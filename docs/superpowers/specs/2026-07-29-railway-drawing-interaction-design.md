# 铁路绘制手感优化设计规格

**日期：** 2026-07-29

**状态：** 已实现并验收（2026-07-30，A 混合模式；152/152 测试通过，
行覆盖率 90.78%）

**所属子项目：** 大区级宏观铁路编辑器交互优化

**参考方向：** 《都市：天际线 II》的连续道路施工、引导与吸附，
《狂热运输 2》的平滑铁路曲线、切线衔接与曲线速度反馈

## 1. 目标

将现有“点击若干控制点后才看到结果”的绘线方式改造成即时、连续、
可预期的铁路建设体验。玩家应能在不反复撤销整条草案的情况下快速绘制
长距离双线，同时清楚判断吸附目标、曲线质量和工程风险。

本次只优化宏观线路输入和预览，不提前实现站场道岔、工程造价、桥隧模型
或列车运行系统。现有确定性拓扑、原子事务、稳定 ID、分块索引和存档格式
继续作为提交后的权威状态。

## 2. 已批准的交互方向

默认采用 A 混合模式：

1. 左键确定起点。
2. 鼠标移动时，从最后一个已确认控制点到光标位置持续显示幽灵双线。
3. 左键确认当前分段，并立即以该点作为下一段起点继续绘制。
4. Enter 完成整条草案；双击仅作为 Enter 的快捷方式，并保证双击位置先成为
   终点，不再漏掉最后一点。
5. 右键在绘线状态下撤回一个控制点；只剩起点时再次右键取消草案。
6. Esc 始终取消整条草案。
7. Shift 按住时临时关闭吸附，松开后恢复。

默认模式兼顾易学与铁路曲线质量。未来的“多点精确模式”和“按住拖拽切线
模式”通过输入策略接口接入，不改变拓扑提交接口。

## 3. 当前问题

现有实现存在以下直接影响手感的问题：

- 光标移动不会更新草案，玩家点击前看不到下一段实际曲线。
- 双击直接提交，双击位置不会可靠地成为终点。
- 右键固定为平移，无法逐步撤回误放的控制点。
- 吸附发生但缺少候选标记、吸附类型和距离反馈。
- 控制点命中半径固定，宏观缩放下难以稳定选择。
- 预览只有单根黄色中心线，看不到真实双线间距。
- 缺少长度、方向、最小曲线半径和预计限速反馈。
- 提交后退出绘制节奏，长线路需要重复选择工具和重新定位。

## 4. 输入状态机

### 4.1 状态

- `Idle`：已选择绘线工具，但还没有起点。
- `Previewing`：至少有一个已确认控制点，并有一个随鼠标移动的临时候选点。
- `DraggingWaypoint`：正在拖动既有控制点。
- `ConfirmingWarning`：草案存在工程警告，等待玩家再次确认。

状态只属于 Godot 输入层和草案会话，不进入世界存档。提交成功后只有生成的
铁路实体进入权威世界状态。

### 4.2 事件

| 输入 | `Idle` | `Previewing` | `DraggingWaypoint` |
|---|---|---|---|
| 左键 | 放置起点 | 确认候选点并继续 | 结束拖动 |
| 双击 | 放置终点后提交 | 确认候选点后提交 | 无 |
| 鼠标移动 | 更新吸附候选 | 更新幽灵线路和指标 | 实时移动控制点 |
| 右键 | 保持现有平移行为 | 撤回一点；只剩起点时取消 | 取消本次拖动 |
| Enter | 提示至少需要终点 | 提交整条草案 | 无 |
| Esc | 返回查看工具 | 取消整条草案 | 恢复拖动前位置 |
| Shift | 临时关闭吸附 | 临时关闭吸附 | 临时关闭吸附 |

鼠标中键始终用于平移。绘线状态下右键不再启动平移，查看、框选和拆分等工具
仍可使用右键平移。

## 5. 草案与预览模型

新增独立的 `RailDrawingSession`，负责管理：

- 已确认控制点；
- 当前光标候选点；
- 当前吸附结果；
- 拖动前控制点位置；
- 工程预览指标；
- 输入策略标识。

`WorldEditorController` 继续拥有最终草案和命令提交职责，但不再直接处理所有
指针细节。`WorldMapView` 将 Godot 输入事件转换为语义动作，例如
`BeginDraft`、`UpdatePreview`、`ConfirmPreviewPoint`、`UndoDraftStep` 和
`CommitPreviewAtCursor`。

预览构建继续使用纯 C# 策略，保证可自动测试且不依赖 Godot 场景树：

```text
已确认控制点 + 临时候选点
        ↓
吸附解析与角度引导
        ↓
平滑中心线采样
        ↓
双线偏移预览 + 工程指标
        ↓
仅在确认后生成 RailGraphPatch
```

临时候选点不加入正式控制点数组，避免每帧鼠标移动污染撤销历史或产生稳定
ID。只有左键确认时才写入草案。

## 6. 吸附与引导

### 6.1 吸附优先级

在同一屏幕距离内按以下优先级选择：

1. 既有铁路拓扑节点；
2. 车站锚点；
3. 既有轨道可拆分位置；
4. 上一个控制点延伸出的角度引导；
5. 自由位置。

同级候选按屏幕距离、稳定 ID 排序，保证相同世界和相同输入得到一致结果。
吸附半径以屏幕像素定义，默认 16 px，并在触控板或高 DPI 环境保持一致。

### 6.2 角度引导

默认提供相对上一段方向的 `0°`、`±15°`、`±30°`、`±45°`、`±90°`
引导。只有候选位置距离引导线不超过 8 px 时才吸附，避免强制扭曲长距离
铁路。Shift 临时关闭包括拓扑目标在内的全部自动吸附，专业设置端口可分别
开关每种引导。

### 6.3 可视反馈

- 吸附目标显示蓝色光环和类型标签。
- 自由候选点显示白色十字。
- 角度引导显示细蓝虚线和角度值。
- 无效吸附显示红色光环并在状态栏解释原因。

## 7. 曲线与双线预览

预览同时绘制中心引导线和上下行两股实际偏移线。两股线使用半透明青色；
中心引导线使用较细的黄色虚线。已确认区段不透明，当前候选区段半透明。

曲线生成保留 `IAlignmentSketchStrategy` 边界。本阶段增强默认策略，使末端
切向同时参考上一已确认区段和吸附目标处的既有轨道方向，减少接入时的折角。
未来可通过同一接口增加：

- `GuidedMultiPointSketchStrategy`：多点精确模式；
- `DragTangentSketchStrategy`：按住拖拽切线模式；
- 专业级圆曲线—缓和曲线策略。

预览指标至少包括：

- 当前候选段长度；
- 草案总长度；
- 最小估算曲线半径；
- 按设计超高的保守预计限速；
- 最大坡度占位值；没有可靠高程纵断面时明确显示“待详细设计”，不得伪造。

预计限速只作为建设预览，不在本阶段改变轨道最终设计速度字段。曲线半径不足、
坡度未知或河流穿越等继续走现有警告确认流程。

## 8. 连续施工与提交

提交成功后默认保持“绘制双线”工具。新草案为空，玩家可立即开始下一条线路。
若终点吸附到既有节点，下一次单击该节点仍能自然开始新的支线。

每次 Enter 或双击只生成一个 `RailGraphPatch`。预览更新、控制点回退和拖动
不写入世界事务历史。提交失败时保留完整草案与候选位置，玩家可直接修正。
警告需要第二次确认时冻结对应草案指纹；鼠标或控制点变化后必须重新确认。

## 9. 性能与确定性

- 光标预览最多按显示帧更新，但纯几何重算节流到最新输入，不排队处理旧位置。
- 预览采样密度按屏幕误差自适应；提交几何使用与预览相同的确定性结果。
- 每帧不创建稳定 ID、不写磁盘、不更新世界空间索引。
- 1000 × 800 km 大区视角和未来大陆级地图均只计算当前草案附近数据。
- 吸附查询复用铁路空间索引和车站分块索引，不遍历全国全部铁路实体。

## 10. 错误处理

- 少于两个不同位置的控制点时禁止提交，并保留绘线状态。
- 候选点与上一点重合时不确认，只显示原因。
- 曲线算法无法生成有效几何时显示红色预览，左键不写入控制点。
- 吸附目标在预览期间被其他事务删除时，重新解析为自由位置或最近有效目标。
- 工程硬错误阻止提交；工程警告按现有二次确认规则处理。
- 切换工具时取消未提交草案，并在状态栏明确提示，不产生世界事务。

## 11. 自动化验收

### 11.1 纯 C# 单元测试

- 一个确认点加一个候选点能产生实时预览，但候选点不进入已确认数组。
- 左键确认候选点后，候选点成为新的最后控制点。
- 右键依次撤回一个控制点；只剩起点时清空草案。
- Shift 禁用吸附，松开后恢复相同候选的确定性吸附。
- 拓扑节点优先于车站、角度引导和自由位置。
- 双击先确认光标位置再提交，不漏终点。
- 角度引导的阈值内吸附、阈值外不吸附。
- 预览包含两股偏移轨道、长度、半径和预计限速。
- 预览几何与最终提交 Alignment 控制点逐点一致。
- 连续鼠标更新不改变世界修订号、历史或稳定 ID 序列。

### 11.2 Godot 输入冒烟

- 选择绘线工具后，首个左键进入预览状态。
- 不点击，仅移动鼠标即可看到幽灵双线变化。
- 连续三次左键形成两段平滑曲线。
- 右键撤回最后一点，中键仍能平移地图。
- Shift 按下时吸附标记消失。
- 双击光标位置后世界中出现包含该终点的双线。
- 提交后工具保持激活，可直接开始下一条线路。
- 运行过程中不存在错误日志或未处理异常。

## 12. 完成标准

本优化只有同时满足以下条件才算完成：

1. 玩家在第二次点击前即可看到准确的幽灵双线。
2. 绘制一条三段线路无需离开绘线工具或操作工具栏。
3. 任意误放点可以用一次右键撤回，且不影响已提交世界。
4. 双击提交不会漏掉光标终点。
5. 吸附目标、长度、半径和预计限速在确认前可见。
6. 预览和提交几何完全一致。
7. 原有改线、拆分、联络线、撤销、存档和分块索引测试不回归。
8. B/C 专业绘制模式具有可替换输入与曲线策略接口，但本阶段不实现其完整 UI。
